# 歴史する 実験版

本番の `doinghistory/site` には変更を加えず、ページごとの構造差を試すために作成したデザイン検証版です。

## 方針
- 共通化するのはヘッダー、色、書体の基本ルールだけ
- 6ページは役割に合わせて構造を変える
- 装飾目的の英字見出しを使わない
- コピーは機能・用途が分かる説明文を中心にする

## ページ
- `manabu.html`：書庫・教材アーカイブ型
- `tou.html`：問いを大きく見せる構成
- `kitaeru.html`：演習を縦に進む構成
- `miru.html`：画像・動画ギャラリー型
- `shiraberu.html`：検索ファースト
- `meguru.html`：雑誌型

## 注意
画像は比較をしやすくするため、一部を現在の公開サイト `https://doinghistory.github.io/site/` から絶対URLで参照しています。別リポジトリで完全に独立運用する場合は、画像を新リポジトリへコピーして相対URLへ変更してください。
