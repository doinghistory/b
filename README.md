## 今回やめたもの
- 角丸カードの連続

- 英字の飾り見出し

- 3カラムカードを機械的に並べる構成

## 今回寄せた方向

- 写真・絵巻・屏風を構造そのものとして使う
- 縦組み、罫線、図録・問題冊子の紙面感
- 日本語中心
- 画像の切り取り方でページごとの個性を出す
